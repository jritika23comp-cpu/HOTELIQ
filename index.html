Start the HotelIQ application

The application pages use Flask templates, authenticated APIs, and the project database. VS Code Live Server only serves static files, so it cannot render the actual pages.

Checking whether the HotelIQ backend is running...

  1. 1Open a terminal in the project folder.
  2. 2Install the project dependencies with pip install -r requirements.txt.
  3. 3Start the app with python run.py.
  4. 4Open HotelIQ using the button below. Do not use Live Server for the application pages.
